# Dream Home Builders NJ

Premium luxury construction company website — cinematic scroll storytelling, GSAP ScrollTrigger, Lenis smooth scroll, and Framer Motion micro-interactions.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Framer Motion
- Lenis
- shadcn/ui primitives
- React Icons / Lucide

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Design

Palette: `#F8F8F7` / `#111111` / `#B8863B` / `#2C2C2C`  
Typography: Cormorant Garamond (display) + Outfit (body)
